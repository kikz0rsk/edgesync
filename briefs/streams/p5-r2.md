  D-26 (no certificates: signing steps skipped), D-27 (licence notices), D-28 (names), D-43 (port, mDNS service type

  builder are Pro; this stream therefore builds packages with its own tools and lets GoReleaser publish them) and 4.4 (native
  runners, no macOS cgo cross-compilation from Windows).
- Verify every GoReleaser key against the v2.19.0 docs (goreleaser.com/customization) and every Info.plist key against Apple's
  Information Property List reference before use. A Pro-only key or a non-existent plist key is BLOCKED, never substituted.

  install/uninstall scripts; quote every expansion; no `curl | sh`; no sudo inside scripts.
- Agents may build binaries and run host-safe tests; they never run EdgeSync binaries and never run the install scripts.
- Package doc comment on every Go package; 85% coverage for every new Go package; `log/slog` only; process execution behind
  an interface in tested code.
- No em dashes or en dashes anywhere; use "-". Commit `<type>(<scope>): <description> [FEAT-NNN]`, body `Item: <id>`, no
  attribution trailers, never push.
