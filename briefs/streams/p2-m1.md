## Scope
The macOS backend in pure Go via `github.com/ebitengine/purego` v0.11.2 (+ `purego/objc`): CoreGraphics event tap
capture with grab and cursor hiding, `CGEventPost` injection, displays, Accessibility/Input Monitoring permissions,
the pasteboard with a lazy `NSPasteboardItemDataProvider`, session events and actions, `NSStatusItem` tray, overlay
panel, LaunchAgent autostart, theme, the AppKit main-thread runner and `internal/platform/host/host_darwin.go`.
Nobody can run anything on a Mac by hand (R-07): evidence comes from cross-compilation on the Windows host and the
`integration-macos` CI job. Every test and report states its evidence level: CI-verified, compile-only, or
unverifiable.

## Conventions (binding)
- Decisions: D-08, D-22, D-34, D-39, D-51, D-52, D-57, D-61, D-71, D-75, D-76 and gap decisions G-01 .. G-03, G-09,
  G-13, G-14, G-16.
- `CGO_ENABLED=0`. Every file builds with `GOOS=darwin GOARCH=arm64` and `GOARCH=amd64` on the Windows host.
  OS-calling files end in `_darwin.go`; pure logic untagged (host-testable, HC85).
- Frameworks: `purego.Dlopen("/System/Library/Frameworks/<F>.framework/<F>", purego.RTLD_NOW|purego.RTLD_GLOBAL)`;
  functions via `purego.RegisterLibFunc`; exported data constants (`kCFRunLoopCommonModes`,
  `kAXTrustedCheckOptionPrompt`) via `purego.Dlsym` + dereference. Private symbols (G-16, R-11) are looked up with
  `Dlsym` and a missing symbol is an explicit error, never a crash.
- Verify every enum value, field number, struct layout and selector against Apple's SDK headers or documentation at
  execution time; the values in this brief are expectations. `CGPoint`/`CGSize`/`CGRect` are float64 pairs passed by
  value (SP4 verified purego handles this on arm64 and amd64; if sp4.md says otherwise, BLOCKED).
- Callbacks (`purego.NewCallback`) created once per signature (G-01); the event tap passes a `refcon` so the tap
  instance is found without global state; Objective-C classes are registered once per process (`sync.Once`).
- AppKit objects are touched only on the main thread through `appkit` (G-09). CGEventTap runs on its own locked
  thread with its own CFRunLoop.
- Autorelease pools: every main-thread work item and every tap callback batch runs inside a pool.
- Pasteboard privacy (R-15): Watch polls `changeCount` and reads `types` only; contents are read only for `Read`
  (a peer's fetch). Contents never logged.
- Integration tests: `//go:build integration && darwin`; log the TCC state (`AXIsProcessTrusted`,
  `CGPreflightListenEventAccess`, `CGPreflightPostEventAccess`) first; tests needing TCC skip with that state as the
  reason when untrusted; they fail only on crashes, unexpected errors, or wrong results for operations that do not
  need TCC.
- No em dashes or en dashes; minimal comments; package docs. Commit scope `darwin`, `ci`, `qa`.

thread and calls `RunMain(m.Run)` style.
