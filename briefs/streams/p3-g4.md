Phase 3, parallel stream. Items: `briefs/plan-phase-3.md` section "G4". Owner tag: `[owner:G4]`.
Read first: `briefs/streams/p3-f.md` sections "Conventions" and "GUI design" (binding), then this brief.

## Scope
Transfers page with the transfer queue (D-12), the send-files dialog (FEAT-098), the Logs page with level filter, live
tail and copy (FEAT-157), the diagnostics export (FEAT-158, FEAT-139), and the About page with the update notice
(FEAT-159). Native OS file drop onto the window is P4 (`gui/drop`), not here.

`gui/transfers/**`, `gui/logs/**`, `gui/about/**`, `internal/i18n/locales/en/gui_transfers.toml`;
`cmd/edgesync/pages.go` only in the registration items with the claim. Read, never edit: `internal/ipc`,

D-12 (queue: progress, speed, cancel, retry, resume), D-17 (receive folder, clash naming is agent-side), D-18 (logs

## Screen: Transfers (design)
- Header: title "Transfers", filter Tabs All / Active / Finished, [Send files...] (primary), [Clear finished].
- Rows (56 dp): direction icon and text "Sending to <machine>" / "Receiving from <machine>"; title (first item name, or
  "<name> and N more", or the folder name); ProgressBar; "<done> of <total>" (`format.Bytes`), speed (`format.Speed`),
  "about 2 min left" (`format.ETA`) for active rows; state text for others: Queued, Completed (with time), Failed
  (reason from the agent), Cancelled. Actions: [Cancel] (Active, Queued; confirm "Cancel this transfer? Files already
  received completely are kept; the partial file is resumed if you retry."), [Retry] (Failed, Cancelled), [Open folder]
  (received and Completed).
- Finished rows stay listed until [Clear finished] (GUI-local, until the GUI restarts).
- Empty: "No transfers yet. Copy files on one computer and paste them on another, or use Send files." + [Send files...].
- Loading until Transfers is loaded; slice error + Retry.

## Screen: Send files dialog (design)
Title "Send files"; "To" SelectBox (paired and connected machines, never this computer; preselected from the
`transfers{send: id}` intent); item list (icon, name, size or "Folder", [Remove]); [Add files...] (on macOS one file per
click because the native multi-file picker is unavailable there; the button text stays the same); [Add folder...];
[Send] (enabled with a target and at least one item); [Cancel] (Escape). Errors: per item ("Cannot read this file:
<reason>") and for the send request (inline at the bottom). On success the dialog closes and the page switches to the
Active filter. No-target state: "No connected machines. Connect a machine on the Machines page." + [Go to Machines].

## Screen: Logs (design)
- Toolbar: level SelectBox (Debug, Info, Warning, Error; default Info), "Follow new records" Toggle (live tail),
  [Copy] (enabled with a selection), [Export diagnostics...].
- List (virtualised `widget.List`, Go Mono 12 sp): time, level badge text, component, message, attributes as
  `key=value`. Click selects a row, Shift+click selects a range, Shortcut+click toggles; Shortcut+A selects all visible
  rows; Shortcut+C copies. Scrolling up turns "Follow" off; turning it on scrolls to the newest record.
- Empty: "No log records at this level."; Loading until Logs is loaded; slice error + Retry.
- Diagnostics panel (inline, under the toolbar when active): explanation "The bundle contains logs, settings with
  secrets removed and system information. It never contains clipboard content or keys."; while running: spinner
  "Creating diagnostics bundle..."; success: "Saved to <path>" with [Copy path]; error: agent message.

## Screen: About (design)
Product name and version (GUI `buildinfo.Version`, commit short hash), agent version (from the snapshot), warning when
they differ ("The GUI and the agent have different versions. Restart EdgeSync."), Go version (`runtime.Version()`),
OS/architecture, "MIT License", project link https://github.com/kikz0r/edgesync (opens with `Env.OpenURL`). Update
section: available -> "EdgeSync <version> is available." + [View release]; manual [Check now] -> "Checking..." ->
"You are up to date." / available / error message; when update checks are off: "Automatic update checks are off." +
[Change in Settings] (`settings{tab: general}`) and [Check now] disabled (D-31: the setting disables checking).

## Item P3-G4-001
`gui/transfers/vm/transfers.go`: `type Row struct{ ID string; Sending bool; Peer, Title string; Done, Total int64;
State RowState; Err string; Speed float64; ETA time.Duration; ETAKnown bool; FinishedAt time.Time }`; rows built from
`snap.Transfers` (the store already applies `TransferProgress`/`TransferFinished`); speed = exponential moving average
of byte deltas over a 3 s time constant, sampled whenever `Present(snap, now)` sees a new `Done` value (synctest-tested
with time steps); ETA unknown when speed is 0; filters; `ClearFinished()` hides finished rows (GUI-local set);
`Actions(row)`; `RequestCancel(id)` -> confirm; `ConfirmCancel(d)`; `Retry(d, id)`; `OpenFolder(d)`.

## Item P3-G4-002
`gui/transfers/page.go` and `rows.go`: the Transfers page per design, states, cancel confirm, consumes the
`transfers{filter: active}` intent and, for `transfers{send: id}`, opens the send-files dialog slot (the dialog itself
arrives in P3-G4-004; until then the intent selects nothing and is consumed: the test asserts the param is taken).
Register the page factory (claim). Keys `gui.transfers.*`.

## Item P3-G4-003
`gui/transfers/vm/send.go`: `Targets(snap)` connected paired peers; `Preselect(id)`; `AddFiles(ctx, pickers)`,
`AddFolder(ctx, pickers)` (run off the frame goroutine by the view; `ErrPickerCancelled` -> no change, no error;
`ErrPickerUnavailable` -> message); items deduplicated by cleaned absolute path; `os.Stat` per item for size or folder
(errors kept per item, the item stays but blocks Send until removed); `CanSend()`; `Send(d)` -> `SendFiles(peer,
paths)`; success -> close + intent `transfers{filter: active}`; error inline.

## Item P3-G4-004
`gui/transfers/senddialog.go`: the dialog per design on `widgets.Dialog`, opened by the page for the send intent and by
[Send files...]. Picker calls happen in goroutines that hand results back through a channel read during the next frame
(and `Invalidate`).

## Item P3-G4-005
`gui/logs/vm/logs.go`: filtering by minimum level over `snap.Logs` (already bounded at 5000 by the store); `Follow`
flag with `ScrolledAwayFromBottom()` turning it off; selection model over visible indices (click, shift-range,
toggle, select all visible; selection cleared when the filter changes); `CopyText()` formats the selected records in
display order as `2006-01-02T15:04:05.000Z07:00 LEVEL component message key=value ...` lines joined by `\n`.

## Item P3-G4-006
`gui/logs/page.go`: the Logs page per design; copy executes `gtx.Execute(clipboard.WriteCmd{Type: "application/text",
Data: io.NopCloser(strings.NewReader(text))})` (the MIME Gio v0.10.3's own `widget.Editor` uses, verified in
`widget/editor.go`); tests read it back with `guitest.Clipboard`. Register the page factory (claim). Keys `gui.logs.*`.

## Item P3-G4-007
`gui/logs/vm/diag.go` + `gui/logs/diag.go`: `Export(ctx, pickers, d, now)`: `ChooseFolder`; cancelled -> no-op; path =
`<folder>/edgesync-diagnostics-<YYYYMMDD-HHMMSS>.zip` (local time from `now`); `DoTimeout("diag.export", 5*time.Minute,
ExportDiagnostics(path))`; success -> path shown with [Copy path] (clipboard write of the path only); error -> agent
message. The GUI adds nothing to the bundle and never reads it.
