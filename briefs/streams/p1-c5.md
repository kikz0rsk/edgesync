# Stream brief - P1 C5 Agent shell

Phase 1 core stream. Items: `briefs/plan-phase-1.md` sections "C5" and "P1-X". Owner tag: `[owner:C5]`. Starts
after the CONTRACT FREEZE (P1-F-022).

## Scope
Everything that turns the core packages into a running agent, minus the real OS backends: per-OS paths, the config
store, logging, i18n, local IPC (endpoints, token, server, client, single instance), the update checker, lock sync,
diagnostics, autostart reconcile, the tray model, the composition root with lifecycle and role switching, the IPC
request handlers, and smoke tests on fake backends.

`cmd/edgesync-agent/main.go` is NOT created in P1: `host.Open` only exists once the P2 streams add
`internal/platform/host/host_<goos>.go`, and the cross-compile gate builds `./cmd/edgesync-agent/...` for all three
OSes. P1 delivers `agent.Main(ctx, args, open, stdout, stderr) int`; the three-line `main` that calls it with
`host.Open` is added after P2 (reported to the parent as a spine gap; the parent appends that item to a later phase).

## Owned paths
`internal/paths/**`, `internal/config/**` (except the frozen `schema.go`, `defaults.go`), `internal/logging/**`
(except `conventions.go`), `internal/i18n/**`, `internal/ipc/**`, `internal/update/**`, `internal/locksync/**`,

`internal/i18n` package doc: "Package i18n provides the message catalogue; every user-facing string goes through T


## Item P1-C5-008
`server.go`:
```go
type Handler interface { Handle(ctx context.Context, client ClientInfo, req msg.RequestBody) (msg.ResponseBody, error) }
type ClientInfo struct { ID uint64; GUI bool; GUIVersion string }
type ServerConfig struct { Endpoint Endpoint; Token [32]byte; Handler Handler; Logger *slog.Logger; MaxClients int /* 8 */; EventQueue int /* 256 */; HelloTimeout time.Duration /* 5 s */ }
func NewServer(cfg ServerConfig) *Server
func (s *Server) Serve(ctx context.Context) error
func (s *Server) Publish(ev msg.IPCEvent)          // to every authenticated client
func (s *Server) PublishTo(id uint64, ev msg.IPCEvent)
func (s *Server) Clients() []ClientInfo
type CodedError struct { Code msg.ErrorCode; Message string } // handlers return it for precise codes
```
Per connection: the first frame must be a request with an `IPCHello` body within HelloTimeout and a token equal under
`TokenEqual`, else the connection closes without a response (no information to unauthenticated peers). Then: a reader
goroutine dispatches each request to the handler in a goroutine (at most 8 in flight per client; the 9th waits),
responses carry the request id; handler errors map to `ErrorInfo`: `*CodedError` -> its code, `context.Canceled` ->
cancelled, `context.DeadlineExceeded` -> timeout, anything else -> internal with the error text. One writer goroutine
per client owns writes; responses and events share its queue (cap EventQueue); a full queue disconnects that client
with a Warn log. Over MaxClients -> close the new connection. Shutdown closes listeners and clients and waits.
