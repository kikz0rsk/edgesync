## Item P2-W1-002
`msgloop` (sonnet). API:
```go
type Thread struct{ ... }                      // one locked OS thread with a GetMessageW loop
func Start(name string) (*Thread, error)       // returns after the thread is ready (message queue created via PeekMessageW)
func (t *Thread) Do(fn func() error) error     // runs fn on the thread, waits, returns fn's error; ErrClosed after Close
func (t *Thread) ThreadID() uint32
func (t *Thread) Close() error                 // posts WM_QUIT (via PostThreadMessageW), waits for exit, idempotent
type Handler func(hwnd windows.HWND, msg uint32, wParam, lParam uintptr) (result uintptr, handled bool)
func (t *Thread) NewWindow(spec WindowSpec, h Handler) (windows.HWND, error) // must run inside Do on that thread
func (t *Thread) DestroyWindow(hwnd windows.HWND) error
type WindowSpec struct{ ClassName string; MessageOnly bool; ExStyle, Style uint32; X, Y, W, H int32 }
var ErrClosed = errors.New("msgloop: thread closed")
```
- `Do` marshalling: a buffered `chan func()` plus `PostThreadMessageW(tid, WM_APP+0x10, 0, 0)` to wake the loop;
  the loop drains the channel when it sees that message. Never block the thread waiting on the caller.
- WNDPROC: one trampoline (`syscall.NewCallback`, created once) registered in every class; it looks up the Handler by
  HWND in a `sync.Map`; unhandled messages go to `DefWindowProcW`. Register the HWND before `CreateWindowExW`
  returns by passing a creation token through `lpParam` and binding on `WM_NCCREATE` (0x0081, `CREATESTRUCTW`
  first field `lpCreateParams`). Remove the entry on `WM_NCDESTROY` (0x0082).
- Message-only windows use parent `HWND_MESSAGE` = `^uintptr(2)` (-3). Hidden top-level windows (needed for
  broadcast messages like `WM_DISPLAYCHANGE` and `WM_SETTINGCHANGE`) use `WS_POPUP` (0x80000000) and are never shown.
- Class registration once per class name per process (guarded map).
- Tests are host-safe (hidden windows only). Leak check: count goroutines before/after with a short settle loop.

## Item P2-W1-008
Hook thread (sonnet). `hook_windows.go`:

  trampolines created once; they read the active instance from an `atomic.Pointer[hookState]` (G-01).

  and up of a swallowed key, track by scan in a [512]bool so an up whose down was swallowed is swallowed too);
