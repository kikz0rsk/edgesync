## Settings behaviour (all tabs)
- Every control applies immediately; there is no global Save. Toggles, radios and selects send on change; text and
  number fields send on Enter or on focus loss after local validation.
- A field shows a pending indicator while its op runs; on agent error the control returns to the agent's value and an
  inline error appears under it until the next change; `ConfigChanged` updates every field that is not pending (for
  example a change made from the tray).
- Tabs: Shortcut+Tab / Shortcut+Shift+Tab cycle; the `settings{tab: ...}` intent selects a tab.
- Loading until Config is loaded (Hotkeys also for the Hotkeys tab; Peers also for Key remap); slice errors with Retry.

## Screen: Settings (design)
- General: Role (RadioGroup Server / Client; change asks "Switching the role disconnects the current sessions.
  Continue?"); "Start EdgeSync when I sign in" (Toggle); Receive folder (TextField with absolute-path validation,
  [Browse] (folder picker), [Open]); "Check for updates daily" (Toggle); "Lock and screensaver sync" group: "Lock other
  computers when this one locks", "Start their screensaver with this one", "Wake their displays when this one unlocks"
  (three Toggles); "Wake machines automatically when the cursor reaches an offline machine" (Toggle); "Clipboard" group:
  "Share the clipboard" (master Toggle) and "Text", "Rich text", "Images", "Files and folders" (Toggles, disabled and
  dimmed while the master is off, values kept); "Log level" (SelectBox Debug/Info/Warning/Error); [Run setup again]
  (secondary button).
- Edge switching: intro "These guards prevent switching by accident. When all are off, the cursor switches as soon as
  it reaches an edge."; four rows, each a Toggle + its parameter (disabled while off) + one-line explanation:
  "Wait at the edge" (NumberField ms, 50..2000, step 10, default 150), "Double-tap the edge" (ms, 150..1000, step 10,
  default 400), "Ignore corners" (px, 0..200, step 1, default 32), "Hold a key to switch" (SelectBox Ctrl / Alt / Shift
  / Win|Cmd|Super, default Ctrl); [Reset to defaults] (confirm). Client role: note "Edge guards apply when this computer
  is the server." and controls disabled.
- Hotkeys: rows "Lock to this screen", "Return home (panic)", "Next machine", "Previous machine", then "Jump to <machine
  name>" for each placed machine in layout order (machines 13..64 start unbound, D-58); each row: binding text (or
  "Not set"), [Change], [Clear] (not on "Return home"); [Reset to defaults] (confirm). Capture dialog: "Press the new key
  combination for <action>. Press Escape to cancel."; shows the combo as it is captured; duplicate -> error "Already
  used by <action>." (cannot save); reserved -> warning "This combination is reserved by <OS> and may not work." (can
  save); [Save] [Cancel]; 15 s without input cancels with "No key combination received." Client role: note "Hotkeys are
  configured on the server." and controls disabled.
- Key remap: machine SelectBox (paired machines); preset RadioGroup "No remapping", "Mac style (Win and Cmd swapped,
  Alt and Option swapped)", "Custom"; Custom shows an 8-row table "Key pressed here -> Key sent to <machine>" for Left
  Ctrl, Right Ctrl, Left Shift, Right Shift, Left Alt, Right Alt, Left Win/Cmd/Super, Right Win/Cmd/Super, each a
  SelectBox of the same 8 keys; "Default" label when the machine has no stored remap (Mac style shown as default for
  machines reported as macOS when the peer list carries the OS; otherwise "No remapping"); [Reset to default]. Empty:
  "Pair a machine to set up key remapping." Client role note "Key remapping is configured on the server."
- Network: Port (NumberField 1024..65535, default 24860; change asks "Machines will reconnect on the new port. Machines
  added by address on other computers must be updated."); "Addresses added manually" list (address:port, [Remove]) +
  an add row (host TextField, port NumberField default 24860, [Add]) with inline validation; empty list text "No
  addresses added manually."

## Item P3-G3-001
`gui/settings/vm/field.go`: generic `type Field[T comparable] struct{ Shown, Agent T; Pending bool; Err string; op
state.OpID }` with `Set(v T, validate func(T) error, send func(T) state.OpID)`, `Resolve(snap state.Snapshot)`
(op done -> `Agent = Shown`, `Pending = false`; op failed -> `Shown = Agent`, `Err` = mapped message),
`FromConfig(v T)` (updates `Shown` and `Agent` only when not pending). `patch.go`: builders producing the
`internal/ipc` config patch value for one field path (`Patch(path []string, value any)`; nested tables like
`sync.lock`, `clipboard.formats.text` or `remap.<peer>`), matching the patch type exactly.

## Item P3-G3-002
`gui/settings/vm/general.go`: fields per "Screen: Settings - General". Role uses `SetRole` after a confirm step
(`RequestRole(r) needsConfirm`, `ConfirmRole(d)`); autostart uses `SetAutostart`; receive folder validates
`filepath.IsAbs` and non-empty, `Browse(ctx, pickers)` uses `ChooseFolder` (cancel -> no change, no error),
`OpenFolder(d)` uses `OpenReceiveFolder`; clipboard per-format fields report `Disabled() == true` while the master is
off (values kept); log level values debug|info|warn|error; `RunSetupAgain(d)` patches `gui.first_run_completed =
false`, `gui.wizard_step = 0` (the shell gate then shows the wizard).

## Item P3-G3-003
`gui/settings/vm/guards.go`: four guards with enabled + parameter fields, ranges and defaults as in the design and D-57;
`ModifierChoices(goos string)` labels the meta key Win (windows), Cmd (darwin), Super (linux); `Reset(d)` restores D-57
defaults in one patch after confirmation; `ClientNote()` true when role is client.

## Item P3-G3-004
`gui/settings/vm/hotkeys.go`: rows built from `GetHotkeys` plus the layout order of placed machines (jump rows for
machines 13..64 unbound by default); display text via the C3 binding formatter; `BeginCapture(d, action)` starts
`CaptureHotkey` with a 15 s `DoTimeout` (timeout -> message, state back to idle); `Escape` cancels (context cancel);
captured combo -> C3 conflict check against the other bindings (duplicate -> error, cannot save) and reserved check
(warning, can save); `Save(d)` sends `SetHotkeys` with the full binding set; `Clear(action)` not allowed for panic
(`ErrPanicRequired`); `Reset(d)` restores D-58 defaults after confirmation. Never re-implement parsing, formatting,
conflict or reserved detection: use the C3 API.

## Item P3-G3-005
`gui/settings/vm/remap.go`: per selected peer: preset detection (identity -> None, Mac table -> MacStyle, else Custom);
`SetPreset(p)`, `SetCustom(from, to keymap.Usage)`, `Save(d)` patches `remap.<peerID>` with the `keymap.Remap` value
in the config's representation; `ResetToDefault(d)` removes the stored table; default display rule per design;
`ClientNote()`.

## Item P3-G3-006
