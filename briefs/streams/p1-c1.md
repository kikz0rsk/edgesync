# Stream brief - P1 C1 Protocol, transport and session

Phase 1 core stream. Items: `briefs/plan-phase-1.md` section "C1". Owner tag: `[owner:C1]`. Starts after the
CONTRACT FREEZE (P1-F-022).

## Scope
Everything between a TLS identity and a routed message: wire fuzzing and codec benchmarks, the transport (QUIC with
datagrams and priorities, TCP+TLS fallback with a strict-priority multiplexer, listener/dialer, pairing
connections), and the session layer (handshake, heartbeat, backoff, routing, motion filter, star-topology connection
manager, layout authority). No pinning logic (C2 provides the `VerifyConnection` func), no engine logic (C3).

## Owned paths
`internal/transport/**`, `internal/session/**`; with a claim: `internal/proto/wire/*_test.go`,
`internal/proto/msg/bench_test.go`, `go.mod`/`go.sum` (P1-C1-004 only).
Leave alone: every other package, all frozen contracts (`internal/proto/wire/*.go` non-test files,
`internal/proto/msg/*.go`, `internal/platform/**`). A contract gap -> BLOCKED with the exact missing API.

## Item P1-C1-002
`internal/transport` package doc: "Package transport carries EdgeSync sessions over QUIC with an automatic TCP+TLS
fallback (D-35, architecture 5.1-5.2)."
`conn.go`:
```go
type Kind uint8      // KindQUIC = 1, KindTCP = 2
type DataClass uint8 // DataClipboard = 1, DataFile = 2
const MaxDataStreams = 4
type FrameStream interface { WriteFrame(f wire.Frame) error; ReadFrame() (wire.Frame, error) }
type MessageStream interface { WriteMessage(b []byte) error; ReadMessage() ([]byte, error) }
type Conn interface {
    Peer() peerid.ID
    Kind() Kind
    Nonce() [16]byte                         // generated by the dialing transport, sent in the opening preamble
    DatagramsSupported() bool
    SendMotion(f wire.Frame) error           // datagram; falls back to Input() when datagrams are unsupported
    ReceiveMotion(ctx context.Context) (wire.Frame, error) // datagram-received frames only
    Input() FrameStream
    Control() MessageStream
    OpenData(ctx context.Context, class DataClass) (io.WriteCloser, error) // blocks while MaxDataStreams are open
    AcceptData(ctx context.Context) (DataClass, io.ReadCloser, error)
    ConnectionState() tls.ConnectionState
    Close(reason error) error
    Done() <-chan struct{}
    Err() error                              // close reason once Done is closed
}
type PairingConn interface {
    Stream() io.ReadWriter
    ConnectionState() tls.ConnectionState
    PeerCertificate() *x509.Certificate
    Close() error
}
```
`ReceiveMotion` is an addition to architecture 5.2 (motion has to be received somewhere); recorded at the freeze.
`errors.go`: `ErrTooLarge`, `ErrClosed`, `ErrDataLimit` (receiver-side violation), `ErrProtocol`, `ErrNoQUIC`
(QUIC handshake did not complete in time; triggers fallback), each `"transport: ..."`.
`framing.go`: length prefix = 4-byte little-endian uint32 followed by the body.
`NewMessageStream(rw io.ReadWriter, max int) MessageStream` (writes serialised by a mutex, a single `Write` of
prefix+body via a reused buffer; reads check `length > max` -> ErrTooLarge BEFORE allocating; zero length is a valid
empty message). `NewFrameStream(rw io.ReadWriter) FrameStream` (wire.Decoder for reads; writes via
`wire.AppendFrame` into a per-stream buffer, mutex-serialised). `WriteHeader(w io.Writer, b []byte) error` /
`ReadHeader(r io.Reader, max int) ([]byte, error)` use the same framing for data-stream headers.

## Item P1-C1-004
`quic.go` / `quic_conn.go`, adds quic-go v0.64.1.
- `quic.Config{KeepAlivePeriod: 1s, MaxIdleTimeout: 5s, HandshakeIdleTimeout: 5s, EnableDatagrams: true,
  MaxIncomingStreams: 4, MaxIncomingUniStreams: 16}` (D-57).
- Dialer side (= server role, D-59) after the handshake: open bidi Input stream, write tag `'I'` + 16-byte nonce;
  open bidi Control stream, write tag `'C'`. Accept side accepts exactly these two in order, validates tags, reads
  the nonce. Wrong tag or order -> close with ErrProtocol.
- Priorities (RFC 9218 urgency 0 = highest): Input 0, Control 1, clipboard data 2, file data 5 incremental. Use the
  exact API recorded in `briefs/spikes/sp5.md`; if that API is absent in v0.64.1: BLOCKED.
- Data streams: uni streams; first byte = DataClass; a semaphore of `MaxDataStreams` per connection on the opener
  side; the accept side counts concurrently open data streams and closes the connection with ErrDataLimit when a
  fifth arrives.
- Motion: `SendMotion` encodes into a pooled 18-byte buffer and calls `SendDatagram`; when
  `ConnectionState().SupportsDatagrams` is false it writes to the Input stream. `ReceiveMotion` decodes with
  `wire.DecodeDatagram`; decode errors are counted (expose `Stats() ConnStats{DroppedDatagrams uint64}` on the
  concrete type) and skipped.
- Close: `CloseWithError(code, reason.Error())` with application error code 0x10 for normal close, 0x11 protocol
  error; `Err()` on the peer reports the remote reason.
- Peer id: `peerid.FromCertificate(cs.PeerCertificates[0])`.

## Item P1-C1-005
`tcpmux.go`: multiplexes three channels over one TLS conn.
- Frame: `[1 byte channel][3 bytes little-endian payload length][payload]`; channels: 1 Motion, 2 Input, 3 Control;
  max payload 64 KiB (control bytes are chunked; input/motion frames are always whole wire frames). Unknown channel,
  oversize or zero-length payload -> ErrProtocol and close.
- Writer: one goroutine owns the conn writes. Pending queues: motion = a single slot (newest frame replaces an
  unsent older one: latest-wins), input = FIFO of wire frames, control = byte FIFO. Each iteration: motion slot
  first, then all queued input frames, then at most one 64 KiB control chunk. So input waits at most one control
  chunk. Writes respect a write deadline from options (default 5 s); a failed write closes the mux.
- Reader: one goroutine demuxes into: a motion channel (buffered 64, drop-oldest with a counter), the input byte pipe
  consumed by `wire.Decoder`, the control byte pipe consumed by the MessageStream framing.
- API: `newMux(conn net.Conn, opts muxOptions) *mux` with `motionWriter`, `inputStream() FrameStream`,
  `controlStream() MessageStream`, `receiveMotion(ctx)`, `close(err)`.

## Item P1-C1-006
`tcp.go` / `tcp_conn.go`: `transport.Conn` over TCP+TLS.
- Connection A: after the TLS handshake the dialer writes preamble `'A'` + 16-byte nonce; then the mux runs.
  `TCP_NODELAY` set on every TCP conn (Go default is on; assert it via `SetNoDelay(true)` explicitly).
- Data connections: `OpenData` dials a new TLS conn (same identity, same verify func, ALPN session) to the same
  address, writes `'D'` + nonce + class byte, returns the TLS conn as WriteCloser. Semaphore of MaxDataStreams.
- Listener side: a registry `nonce -> *tcpConn` populated when connection A is accepted; an incoming `'D'`
  preamble is matched by nonce AND by peer id (from TLS); mismatch -> close the data conn (log at Warn, no reply).
  Over the limit -> close the data conn and the session with ErrDataLimit.
- `DatagramsSupported()` false; `SendMotion` -> mux motion slot; `ReceiveMotion` -> mux motion channel.
- `Close` closes connection A and every open data conn, removes the registry entry.

## Item P1-C1-007
`listen.go`, `dial.go`, `resolve.go`.
```go
type ListenConfig struct { Port int; TLS *tls.Config; Logger *slog.Logger }
func Listen(ctx context.Context, cfg ListenConfig) (*Listener, error) // UDP ":port" (QUIC) + TCP ":port", all interfaces, dual stack
func (l *Listener) AcceptSession(ctx context.Context) (Conn, error)
func (l *Listener) AcceptPairing(ctx context.Context) (PairingConn, error)
func (l *Listener) Addr() (udp, tcp net.Addr)
func (l *Listener) Close() error
type DialConfig struct { TLS func(alpn string) *tls.Config; QUICTimeout time.Duration /* default 1.5 s */; Logger *slog.Logger }
func Dial(ctx context.Context, addr string, cfg DialConfig) (Conn, error)          // addr "host:port"
func DialPairing(ctx context.Context, addr string, cfg DialConfig) (PairingConn, error)
```
- Routing on accept: QUIC conns by `NegotiatedProtocol` (session -> two-stream setup; pairing -> accept one bidi
  stream); TCP conns: pairing ALPN -> PairingConn over the TLS conn; session ALPN -> read preamble byte `'A'` (new
  session) or `'D'` (data conn for an existing session, P1-C1-006).
- Dial: resolve with `net.DefaultResolver.LookupNetIP(ctx, "ip", host)` (literal IPs skip resolution); for each
  address in returned order: QUIC with a `QUICTimeout` context; success -> return; a TLS/verification failure is
  returned immediately (no fallback: the peer answered); timeout / no UDP response -> TCP dial; first success wins;
  all failed -> joined error (`errors.Join`) naming each attempt.
- Queues between the internal accept goroutines and `AcceptSession`/`AcceptPairing` are buffered (16); a full queue
  closes the newest conn with a logged reason.
- TestDial_FallsBackToTCPWhenUDPSilent: bind a UDP socket on the target port that reads and discards everything,
  plus a real TCP listener; assert `Kind() == KindTCP` and total time < 3 s.

## Item P1-C1-010
`internal/session` package doc: "Package session runs authenticated EdgeSync sessions: handshake, heartbeat,
routing and the star-topology connection manager (D-59)."
```go
type LocalInfo struct {
    Name, OS, BuildVersion string
    Role msg.Role
    Capabilities msg.Capabilities
    MACs []net.HardwareAddr
    Broadcast []netip.Addr
    Desktop platform.Desktop
}
type Admission func(peer peerid.ID, hello msg.Hello) *msg.Reject // nil admits
type RejectedError struct { Reject msg.Reject }                  // returned to the dialer
func DialHandshake(ctx context.Context, c transport.Conn, local LocalInfo) (msg.Hello, error)
func AcceptHandshake(ctx context.Context, c transport.Conn, local LocalInfo, admit Admission) (msg.Hello, error)
```
- Dialer sends `Hello{ProtocolVersion: buildinfo.ProtocolVersion, SessionNonce: c.Nonce(), PeerID: own id, ...}` on
  Control and waits up to 5 s (D-57) for Welcome or Reject. Acceptor reads Hello (5 s), checks:
  `ProtocolVersion` equal (else Reject versionMismatch with detail "local N, remote M"); `Hello.PeerID == c.Peer()`
  (else close with ErrProtocol, no Reject: identity mismatch); `SessionNonce == c.Nonce()` (else ErrProtocol);
  `admit` (Reject on non-nil). Success -> Welcome{Info: own Hello}.
- Any other message before the handshake completes -> ErrProtocol.
- Error type: `*RejectedError` implements `error` with the reason name; `errors.As` works.

`backoff.go`:

## Item P1-C1-013
`session.go`, `router.go`, `motion.go`.
```go
type ControlHandler interface { HandleControl(ctx context.Context, s *Session, m msg.Control) error }
type DataHandler interface { HandleData(ctx context.Context, s *Session, h msg.DataHeader, r io.ReadCloser) error }
type FrameHandler interface { HandleFrame(s *Session, f wire.Frame) }   // Key, Button, Wheel, ReleaseAll, ModSync, MotionAbs
type Router struct { /* immutable after Freeze */ }
func (r *Router) Handle(k msg.Kind, h ControlHandler)
func (r *Router) HandleData(c transport.DataClass, h DataHandler)
func (r *Router) Freeze()                                               // panics if called twice (impossible-state)
type Session struct{ ... }
func New(c transport.Conn, remote msg.Hello, r *Router, frames FrameHandler, l *slog.Logger) *Session
func (s *Session) Run(ctx context.Context) error   // starts: control reader, input reader, motion reader, data acceptor, heartbeat; returns the first fatal error
func (s *Session) Peer() peerid.ID
func (s *Session) Remote() msg.Hello
func (s *Session) SendInput(f wire.Frame) error
func (s *Session) SendMotion(f wire.Frame) error
func (s *Session) SendControl(m msg.Control) error
func (s *Session) OpenData(ctx context.Context, class transport.DataClass, h msg.DataHeader) (io.WriteCloser, error) // writes the header
func (s *Session) Close(reason error) error        // Goodbye best effort (250 ms bound), then conn close; idempotent
func (s *Session) RTT() time.Duration
func (s *Session) Stats() Stats                    // DroppedDatagrams, DroppedStaleMotion, ProtocolErrors
```
- Control reader: `msg.DecodeControl`; Ping -> Pong; Goodbye -> close with remote reason; handshake kinds ->
  ErrProtocol; otherwise route by `msg.KindOf`; no handler -> ErrProtocol (closes: an unknown message means a
  version skew the handshake should have caught). Handler errors are logged and do not close the session unless they
  wrap `ErrFatal` (exported sentinel).
- Input reader: Heartbeat -> HeartbeatAck; HeartbeatAck -> `heartbeat.Ack`; MotionAbs -> motion filter -> frames;
  other types -> frames. `wire.ErrUnknownType` on the stream -> close (architecture 5.4).
- Motion reader: `ReceiveMotion`; decode errors counted (DroppedDatagrams); filter; frames.
- Data acceptor: per stream: `ReadHeader` (cap `msg.MaxControlBytes`), `msg.DecodeDataHeader`, dispatch to the class
  handler in its own goroutine (tracked by a WaitGroup); class without handler -> close that stream.
- Every received packet calls `heartbeat.Observe()`.
- `motion.go`: `type MotionFilter struct{ last uint32; has bool }`, `Accept(seq uint32) bool` with RFC 1982 serial
  arithmetic (`int32(seq-last) > 0`), first frame always accepted; reset on `Enter` (exported `Reset()`; the engine
  client calls it through the session on Enter).
- Run returns only after every goroutine it started has exited.
