# Stream brief - P5 R1 Windows installer (Inno Setup 7.1.1), service install, firewall, autostart, SAS policy

Phase 5. Items: `briefs/plan-phase-5.md` section "R1". Owner tag: `[owner:R1]`. Agent: `go-dev` (`model` per the item's
tier); review items are dispatched as `code-reviewer`.

## Scope
Produce the Windows installer described by D-25, D-118 and FEAT-163: one per-machine installer per architecture (Inno Setup
7.1.1, D-118; amd64 and arm64, D-104) that installs the GUI, agent and SYSTEM service into `%ProgramFiles%\EdgeSync`, registers
the service with failure recovery through our own `edgesync-service install` subcommand, adds firewall rules for the agent,
registers machine-wide autostart (D-116), sets the `SoftwareSASGeneration` policy needed for `SendSAS`, protects
`%ProgramData%\EdgeSync`, closes running EdgeSync processes on upgrade and uninstall, and uninstalls cleanly. Plus the release
helpers it needs (`isbuild`: build, stamp, sign), the CI jobs that compile the installers and run the install lifecycle on the
runners, the small code changes the installer depends on (machine autostart mode, installer close handshake, firewall
subcommands), and the manual install/upgrade/uninstall script.
