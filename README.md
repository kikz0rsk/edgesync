# EdgeSync

EdgeSync shares one keyboard and mouse across Windows, macOS and Linux computers on the same network. Move the cursor across a screen edge to control the neighbouring computer. The clipboard is shared as well (text, rich text, images and files), and files can be transferred with copy-paste and drag-and-drop.
